# Product scope

B2B SaaS for training centers. Every tenant owns users, students, teachers, courses, groups, attendance, finance and certificates.

Core modules: authentication, tenant isolation, RBAC, CRM-lite student records, course catalog, cohorts, schedules, attendance, billing, certificates, reports, AI assistant, subscription billing, analytics, audit log.

Production integrations: PostgreSQL, Stripe webhooks, PostHog, AI provider, email/WhatsApp provider.
